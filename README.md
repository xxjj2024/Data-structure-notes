# 数据结构笔记（源码 + 教材）

本仓库包含《数据结构》课程的学习资料，配套严蔚敏版《数据结构（C语言版）》教材，收录了课程学习中实现的各类数据结构 C++ 源码。

## 目录结构

- `数据结构 严蔚敏.pdf` —— 教材电子版（严蔚敏《数据结构（C语言版）》）
- `源码/` —— 各数据结构章节的 C++ 实现源码

## 内容覆盖章节

1. **线性表**：顺序表、单链表、循环链表、双向链表、静态链表
2. **栈与队列**：顺序/链式存储、循环队列、栈的应用
3. **串**：顺序串、堆串
4. **树与二叉树**：二叉树遍历、线索二叉树、二叉排序树、AVL 树
5. **图**：邻接矩阵/邻接表、DFS/BFS 遍历、Prim/Kruskal 最小生成树、拓扑排序、关键路径、最短路径
6. **查找**：二叉排序树、AVL 树、哈希表
7. **其他**：排序算法、稀疏矩阵、广义表

## 使用说明

每个子目录均为独立的 Visual C++ 工程（支持 VS 及 VC6 的 `.dsw`/`.dsp`），包含 `.h` 头文件与 `.cpp` 实现文件，可直接打开编译运行；也可将源文件加入任意 C++ 编译环境单独编译。
